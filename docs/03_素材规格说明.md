# JCL 素材规格说明

网站按 **ID** 自动加载素材，无需改代码：把文件放入对应目录、文件名 = ID 即可（演示版为程序生成的 SVG 占位，真实素材同名覆盖）。

## 1. 选手头像（必须遵守）
| 项 | 要求 |
|---|---|
| 内容 | 自选**非本人**头像（游戏头像、动漫/插画、图标均可；不得使用本人照片、他人肖像、侵权商业 IP 的高清原图） |
| 比例 | **1:1 正方形** |
| 尺寸 | **512×512 px**（不低于 256×256） |
| 格式 | PNG / JPG / WebP（首选 WebP 或 PNG） |
| 体积 | ≤ 300 KB |
| 构图 | 主体居中；网站会裁成**圆形**，四角约 15% 区域可能被裁掉，勿把关键内容放在边角 |
| 命名 | `{选手ID}.webp`（如 `mit-1.webp`），放入 `public/assets/players/` |
| 缺失 | 自动显示首字母占位 |

## 2. 选手信息字段（每人）
游戏 ID（`gameId`）、展示 ID（`displayName`，网站显示用）、头像、位置（可选）、年级/班级（可选）。

## 3. 队伍
- 队名（`name`）、简称（`tag`，2–4 字母）、队标。
- 队标：**正方形 512×512，透明背景 PNG 或 SVG**，体积 ≤ 200 KB，主体留 10% 边距。命名 `{队伍ID}.png|svg`，目录 `public/assets/teams/`。

## 4. 英雄头像
- 正方形 **128×128 px**（可 256 以适配高分屏），PNG/WebP，≤ 40 KB。
- 命名 `{英雄ID}.png`，目录 `public/assets/heroes/`；ID 与 `src/data/heroes.json` 一致。

## 5. 装备图标
- 正方形 **96×96 px**，PNG/WebP，≤ 30 KB，透明或纯色底均可。
- 命名 `{装备ID}.png`，目录 `public/assets/items/`；ID 与 `src/data/items.json` 一致。

## 6. 其他
- 首页奖杯/海报在 `public/assets/brand/`，可替换同名文件。
- 数据录入（截图→JSON 由 LLM 完成）的指引文档暂缓，格式以 `src/data/2026-fall/matches.json` 为准，`npm run check` 会校验。
